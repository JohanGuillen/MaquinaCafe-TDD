
# Máquina de Café - TDD

## Descripción
Proyecto desarrollado en Java utilizando la metodología de Desarrollo Guiado por Pruebas (TDD).

## Tecnologías utilizadas
- Java
- Maven
- JUnit 4
- Git y GitHub
- IntelliJ IDEA

## Funcionalidades
- Gestión de vasos pequeños, medianos y grandes.
- Control de disponibilidad de café.
- Control de cantidad de azúcar.
- Preparación de café.
- Pruebas unitarias automatizadas.

## Integración continua
El proyecto utilizará GitHub Actions para automatizar la compilación y ejecución de pruebas.
